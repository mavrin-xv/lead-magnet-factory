# Formats and when to use each

Pick the format from the reader's stage and the job, not from what is easiest to write.

## By reader stage

| Stage | The reader is thinking | Formats that fit |
|---|---|---|
| Awareness | "Something is wrong, I am not sure what" | Checklist, quiz, audit, short report with one striking finding |
| Consideration | "I know the problem, how do people solve it?" | Playbook, swipe file, template, comparison, mini-course |
| Decision | "Is this offer right for me?" | Calculator, sample of the paid thing, case study, free trial week |

## The formats in this pack

| Format | Shape | Best for | `magnet_lint.py --format` |
|---|---|---|---|
| Checklist | 20 to 25 checkbox items, each with why and how to check | Showing gaps fast; launch or routine tasks | `checklist` |
| Playbook | 5 to 7 steps, each with context, action, example, anti-example | A process the reader repeats | `playbook` |
| Swipe file | 15 to 20 ready-to-use entries: full text, why it works, when to use | Anything the reader must write or say | `swipe` |
| Template | How to use it, the blank with `[PLACEHOLDERS]`, a filled example | Planning, setup, documents | `template` |
| Mini-course | 3 to 5 lessons: problem, solution, action, self-check | Concepts the reader misunderstands | `course` |
| Hub | All five above on one page, each from a different angle | A flagship magnet for a broad audience | `hub` |
| Interactive | Quiz, calculator, AI-graded audit | Reveal-a-problem and decision stage | see `magnet-writer/references/interactive-formats.md` |

Counts outside the range are a warning, not a failure, down to a floor (checklist 10, playbook 3, swipe 8, course 2).

## Picking from the input

| The input mostly contains | Lean toward |
|---|---|
| Steps in order, "first I...", "then..." | Playbook |
| Lists of things to check, mistakes | Checklist |
| Messages, scripts, captions, emails that worked | Swipe file |
| A document or plan the owner reuses | Template |
| "People don't understand why..." | Mini-course |
| Numbers, pricing, costs, "how much" | Calculator |
| A diagnosis the owner does on calls | Audit or quiz |

## Gating (how much to ask for)

- Ask for the fewest fields that deliver the magnet: one field (email or a DM) beats three.
- Full gate: the whole magnet behind the opt-in. Fine for checklists and templates.
- Partial gate: the first section public, the rest after opt-in. Good for long playbooks: the public part proves the quality.
- Content upgrade: a bonus file on one specific blog post, tied to that post's topic. Converts above a generic sidebar offer because the reader already wants the topic.
- Ungated: the page is public and the next step is the opt-in. Use when reach matters more than the list.
