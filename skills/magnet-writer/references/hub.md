# The hub page: five angles, no overlap

A hub is one flagship page that holds a playbook, a checklist, a swipe file, a template and a mini-course on the same topic. Done badly it repeats the same advice five times. The fix is to give each section a different question to answer.

| Section | Answers | Contains | Does not contain |
|---|---|---|---|
| Checklist | Am I ready? | Yes/no checks with how to verify | Explanations longer than a clause |
| Playbook | How do I do it? | Steps in order with examples | Why the method works |
| Swipe file | What do I say or write? | Full, ready-to-paste texts | Steps |
| Template | How do I set it up? | One blank + one filled example | Advice |
| Mini-course | Why does it work? | The concepts behind the steps | Instructions already in the playbook |

## Order

1. Checklist first. It is the fastest win: the reader scores themselves in five minutes and sees the gaps.
2. Playbook. It closes the gaps the checklist showed.
3. Swipe file and template. The tools for doing the playbook steps.
4. Mini-course last. For readers who want to understand, not just do.
5. One `## Next step` at the very end, not one per section.

## Size

Aim for 80 to 120 blocks in total (a block is a heading, paragraph, list item or callout). Put long sections inside toggles so the page stays scannable. Before writing, list the 5 to 8 points the topic has, then assign each point to exactly one section. If a point fits two sections, it belongs to the one whose question it answers.

## Headings

The lint looks for `##` headings containing the words playbook, checklist, swipe, template and course. Example: `## The checklist: am I ready?`.
