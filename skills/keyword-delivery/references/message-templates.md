# Message templates

Replace the words in angle brackets. Keep the shape.

## Public replies (rotate 3 or more, each 100 characters or fewer)

```
Sent, check your DMs.
In your inbox now. Tell me which step you start with.
Done. The <magnet> is in your DMs.
On its way. If it did not arrive, check message requests.
```

Post the public reply after the DM goes out, so the person sees the DM is already there. The "message requests" variant helps people who do not follow you yet: their DM may land there.

## First DM (2 sentences or fewer, no link, one button)

```
Here is the <magnet> you asked for. Tap below and I will send the link.
[ Send the <short name> ]
```

Variants:

```
You asked for the <magnet>. One tap and it is yours.
[ Get it ]
```

```
<Magnet> coming up. Tap to get the link.
[ Send it ]
```

Why short: on a phone the preview shows the first line only. The button is the only thing to do.

## Link DM (after the tap)

```
Here it is: <link>
Start with <the quick win section>, it takes <N> minutes.
(Automated reply. Write here any time and a person answers.)
```

The second line points at the quick win, so the first visit ends with a result. The third line is the disclosure and the human path in one.

## Follow-up (optional, inside the window, only to people who tapped)

```
Did the <magnet> open? Reply with <one detail> and I will send <one specific extra>.
```

Ask for a reply, not a click. A reply opens a conversation and a new window; a second link is just noise.

## Telegram bot

```
/start dialin_reel  ->
Here is the <magnet>: <link>
Start with <the quick win section>, it takes <N> minutes.
This is a bot. Reply here and a person reads it.
```

Telegram has no comment trigger, so there is no first DM: the person already chose by opening the link.

## Email (form flow)

Subject: `Your <magnet>`
Body: the link in the first line, the quick-win pointer, one sentence on what the email list sends and how often, and the unsubscribe line your tool adds.
