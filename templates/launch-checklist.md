# Launch checklist: [MAGNET TITLE]

## Before

- [ ] `magnet_lint.py` passes with no FAIL, and the model half of the quality gate is done
- [ ] The public link opens on a phone, in a private window, without a login
- [ ] `flow_builder.py` passes with no FAIL; the DM tool is set up from `flow.md`
- [ ] Tested from a second account: keyword in lower case, near miss, double comment, button, reply reaches a person
- [ ] `promo_check.py` passes with no FAIL
- [ ] The keyword is spelled the same in the video, caption, image and pinned comment
- [ ] Someone will read DM replies for the first 48 hours

## Launch day

- [ ] Post on the main channel first, pin the keyword comment
- [ ] Answer the first comments by hand within the first hour
- [ ] Check that DMs are being delivered (tool dashboard: triggered vs sent)

## Days 2 to 7

- [ ] Post on the other channels, one per day, each with its own give-away angle
- [ ] Read every question people sent back; note gaps in the magnet

## Week 2 onward

- [ ] Fill in the step rates from `keyword-delivery/references/measurement.md`
- [ ] Fix the weakest step, one message at a time
- [ ] Re-share the best post with a different give-away item
- [ ] Update the magnet with the answers to the questions people asked
