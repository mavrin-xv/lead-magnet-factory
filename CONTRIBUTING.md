# Contributing

Issues and pull requests are welcome.

- **Bug:** include the command, the input file (or a short version of it) and the full output.
- **New format:** add its structure to `skills/magnet-writer/references/format-structures.md`, a template in `templates/`, and its counts to `magnet_lint.py`.
- **Platform rule changed:** update `promo_check.py` or `flow_builder.py` and the matching reference, with a link to the platform's own docs.
- **Skill changes:** show a before and after output on the invented data in `examples/`.
- Scripts stay standard-library only, so the pack installs with nothing but Python.
- Plain English in docs. No invented numbers in examples; example companies are fictional.

By contributing you agree your work is released under the MIT license.
